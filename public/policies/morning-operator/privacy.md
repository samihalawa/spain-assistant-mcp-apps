# Morning Operator privacy information

Morning Operator is an instruction package maintained by Sami Halawa. It contains a personal workflow for a one-off review of current work. It does not bundle an MCP server, account, mailbox, CRM, browser service or publisher-operated data collection endpoint.

When invoked, the assistant may inspect the repositories and connected sources available in the host and authorized for that request. Those tool calls can read or change records in the selected systems. Relevant content and results become part of the host conversation or artifacts it saves. The package does not independently implement storage, deletion or retention for those systems.

The host assistant and each connected service govern their own storage and account data. Removing this instruction package does not delete chats, files or records created through those services. Review or delete such data through the corresponding host or service. No automatic retention or deletion period is promised by this package.

For package questions, use the support link in this repository. Do not include private work records or credentials in public issues.
